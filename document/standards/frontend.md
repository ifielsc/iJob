# 前端代码与界面规范

采用现有 Vue/TypeScript 模块结构。跨模块只能通过 `public/components.ts` 或 `public/contracts.ts`；详细依赖边界以源码[模块契约](../../develop/web/ijob/src/modules/README.md)和自动检查为准。Pinia 管理客户端状态，TanStack Query 管理服务器状态。不要缓存秘密、自动重试有副作用的写请求，或用主题/语言切换改变业务查询身份。

复用 shared UI、主题 token 和统一表单/列表/抽屉组件，不在业务页面复制一套颜色、间距或错误处理。品牌继续为 iJob HELIX，登录页、导航和 favicon 保持一致，不把个人账号名称作为产品品牌。默认浅色、简体中文，同时维护深色与英文；登录时显式继承登录页主题/语言，账户时间模式独立保留。UTC 存储、展示时区和业务时区不得混用。

字号基线为正文 13、辅助 12、页标题 24、抽屉标题 18；主按钮高 36、查询 32、批量 30。常规抽屉宽 520，复杂抽屉 640，小屏自适应全宽。表单标签间距 5、辅助说明 6、分组间距 16，延续现有 token；调整统一组件时同步核验明暗主题与中英文，不逐页引入特例。

编辑表单保留草稿、焦点与离开提醒；主题和语言切换不能丢失未提交输入。接口中的缺省、null 与 false 语义明确，秘密字段使用保留/替换/清除的显式操作，不以空展示值误清除。列表选择、分页、排序、权限禁用原因和抽屉关闭行为沿用统一组件契约。

通知预览使用后端真实模板渲染，只预览而不发送；预览入口使用现有左侧蓝色眼睛图标，操作区固定在抽屉底部。失败与空态表达实际后端状态，前端不伪造成功消息。权限控制同时覆盖 UI 与服务端，不因隐藏按钮就省略 API 鉴权。

通知预览采用通知语言和时区，邮件在隔离 iframe 展示；草稿格式进入预览，凭据与目标地址不进入预览请求。取消过期请求，失败清空旧正文。编辑抽屉固定头尾、内容局部滚动，Esc 优先关闭内部弹层，关闭继续执行草稿守卫并恢复焦点。只读详情用可复制文本，不用禁用表单替代阅读界面。

调度参数表使用既有独立 compact 模式，在窄屏保留五列；不能把其他参数表的 640px 最小宽强加于调度场景，也不能反向覆盖参数定义表。图首次适应画布后，刷新、最大化与还原保留视角和选中状态。界面变更检查桌面及 390/320px、双语、明暗主题和实际 scrollWidth；不以整页没有滚动条代替局部溢出核验，不为截图发送通知或执行任务。

Node 和 pnpm 版本以 `.node-version`、`package.json` 为准，锁文件冻结安装。提交前通过运行时、类型、lint、模块边界、格式、单元、构建、bundle 和浏览器检查；涉及真实后端的完整验证遵循隔离集成入口。
