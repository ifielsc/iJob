# 经典案例

[English](../en/examples.md) · [手册首页](README.md)

先在独立练习环境完成快速入门。以下案例只使用练习账号、目录、数据库或模拟接口；资源密码在资源表单的秘密字段填写，不写入脚本、环境变量或报告。外部服务需要另行准备，不会因导入任务自动安装。

## A. 脚本成功、失败和停止

按快速入门创建 SCRIPT 任务，Windows 用 BAT，Linux/Docker 用 SHELL。`echo hello-ijob` 后 `exit 0` 应为 SUCCESS；改为 `exit 7` 发布并运行应为 FAILED。重试次数设为 0，方便观察单次执行。

停止练习可在 Linux 使用 `sleep 30`，Windows 使用 PowerShell 引擎和 `Start-Sleep -Seconds 30`（需要该 Worker 安装 PowerShell）。运行后在运行中心选择对应实例停止，等待终态；不要通过关闭浏览器判断停止成功。检查执行节点、停止记录和最终状态。恢复正常脚本后再次发布。脚本生命周期日志记录退出状态，不自动记录脚本标准输出。

## B. HTTP 调用和结果提取

在“资源管理 → 服务资源”创建一个指向练习 HTTP 服务的资源，选择实际认证方式。在任务管理新增 API_CALL，选择该资源、HTTP、GET 和练习路径 `/orders/count`，请求体留空。练习服务应返回 HTTP 200 和 `{"count":2}`。

先保存并手动执行，检查状态及结果字段。再在表单的提取规则中将结果字段 count 提取为变量，使用页面支持的表达式格式和预检检查，随后可在作业中引用直接上游的结果。不要把模拟响应写成真实业务响应，也不要用有副作用的 POST 练习网络重试。Docker 中 localhost 是执行容器，不是宿主机或浏览器电脑。

## C. SQL 查询与文件浏览

准备独立练习数据库，在数据库资源中填写驱动、连接、账号并检查连接。新增 SQL 任务选择该资源，输入 `SELECT 1 AS sample_value`。先使用 SQL 预览检查结果，再保存和手动执行，查看运行状态。预览是受限只读查询；DDL/DML 不属于预览功能，不能把预览成功等同写入任务成功。

在文件资源中设置独立测试根目录，使用文件浏览按钮选择文件。LOCAL 路径属于当前节点；草稿浏览须配置 `app.resource-browser.local-roots`。FTP/SFTP/S3 需要自己的服务与账号，SFTP 首次连接核对主机指纹。文件传输练习选择一个小文本文件，源与目标目录分开，先核对覆盖策略，再运行并比较目标文件内容。不要把平台数据库或密钥目录当作传输源。

## D. ETL 与批量选表

在两个独立练习数据库中准备源表 `sample_orders(id, amount)`、两行样例数据及目标表，明确主键和字段类型。配置源/目标数据库资源，新增 ETL 任务，选择表或查询读取、字段映射和写入方式。先关闭自动重试并用少量数据运行，核对目标行数、主键和 amount 值；只看 SUCCESS 不足以证明数据正确。

增量模式需明确增量列、初始水位和边界，运行后查看检查点/进度；修改配置后的旧检查点不应当作新配置已执行的证据。不要直接删除检查点来强制重跑真实数据。

批量场景使用 BATCH_ETL，打开选表弹窗，搜索并勾选两张练习表，核对源表到目标表的映射和数量，再保存运行。切换资源后重新核对表清单。目标存在的数据、覆盖/建表策略应先在样例库验证。

## E. 分支、子作业与日历

从两个节点的 hello-flow 扩展：添加一个网关、两个下游任务，每条分支使用不同标识和优先级，设置且只设置一条默认分支。非默认条件可用输入变量，例如布尔变量 `approved`；通过条件编辑器选择变量、比较操作和值，不手工拼接未知条件 JSON。执行时传入对应输入，分别观察命中分支和默认分支的状态。

子作业先独立发布，再加入父作业并发布父作业。父作业保存时重新绑定当前引用版本；历史运行拓扑反映当次发布引用，不跟随未来编辑变化。自动布局和连线样式只影响展示。

需要工作日触发时，先在日历管理配置允许日期和例外日期，将日历关联到调度，预览检查被排除的日期。时区、有效期和错过触发策略必须共同核对；补发会产生实际执行，不在生产调度上试验。

## F. 在两个环境之间导入导出

在源端任务或作业列表选择练习对象并导出，按需附带资源非秘密配置、调度或通知引用。目标端先准备自己的资源及凭据，再依次上传校验、映射、新增/复用/更新选择、检查差异和确认导入。

新建任务/作业和新建调度默认停用。复用不会改写目标启停状态；确认复用对象是目标环境的正确对象。导入后核对资源、版本、参数、调度，再手动启用。部分完成先查看同一个导入记录，修复原因后继续；网络错误不要反复创建新计划。HTML/JSON 报告是配置迁移结果，不证明外部服务连通或任务已运行。CLI 连接文件必须保存在受限目录，不把密码放到命令行。
