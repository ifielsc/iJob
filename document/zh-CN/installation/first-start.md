# 首次初始化与登录

[English](../../en/installation/first-start.md) · [手册首页](../README.md)

准备好完整程序包后，按所选平台配置一个独立实例。公开下载状态见[安装选择](../installation.md)。

## 1. 配置实例入口

按 [Windows](windows.md)、[Linux](linux.md) 或 [Docker](docker.md) 指南运行 configure，指定独立控制目录和数据目录。configure 不启动程序，也不创建网页登录会话。

## 2. 首次启动并初始化

1. 从刚配置的实例控制目录运行 start。
2. 新安装按提示选择平台数据库，创建自己的管理员账号和密码。
3. 入门可选单实例 SQLite；选择服务数据库不会自动变成集群。
4. 等待初始化和启动完成，检查该实例的状态与日志。

已有有效安装保留原配置，不要重复初始化覆盖。平台库与练习用业务库分开。

## 3. 首次登录

默认本机访问地址为 `http://127.0.0.1:18080`；修改端口后使用实际地址。输入初始化时创建的账号，不存在随文档分发的通用账号密码。若页面要求首次改密，完成改密后再操作。

登录后检查工作台中的节点就绪状态，再按[快速入门](../quickstart.md)执行一个无外部写入的脚本。能够登录、节点就绪与业务执行成功是三项不同检查。

## 常见问题

| 现象 | 下一步 |
| --- | --- |
| 地址无法打开 | 核对端口、进程身份、启动日志和容器健康 |
| 账号不正确 | 确认 STATIC/DATABASE 模式及初始化时的账号来源 |
| 只能查看，不能创建 | 创建需要 ADMIN，参阅权限矩阵 |
| 登录成功但任务等待 | 检查 Worker、执行分组、并发和资源条件 |
