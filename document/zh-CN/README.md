先用[概念模型与执行生命周期](concepts.md)理解定义和运行的关系，再查[独立术语表](glossary.md)。系统参数和自定义输入见[变量表达式参考](reference/variables.md)；角色能做什么见[权限矩阵](user-guide/users-audits.md)。

[版本与更新记录](releases.md)说明当前 1.0.0 的文档范围。

程序包与 IJOB_HOME 分开；后者包含配置、秘密和数据。文档中的界面截图来自真实环境，并使用合成账号与样例数据。按对应页面的适用条件准备自己的资源和参数。
