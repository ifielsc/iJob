# iJob 1.0.0 用户手册

[English](../en/README.md)

iJob 用于配置、编排、调度和观察任务。仓库目前保持私密，文档和交付按可独立部署的项目维护。代码的 MIT 许可不代表所有第三方二进制已获公开再分发签收。

第一次使用请依次阅读：

1. [安装、构建与启停](installation.md)：从源码 ZIP/克隆构建，或使用完整交付包。
2. [快速入门](quickstart.md)：创建、运行并查看第一个任务。
3. [配置参考](configuration.md)：外部配置位置、可调整项和检查命令。
4. [经典案例](examples.md)：脚本、HTTP、SQL、文件、ETL、DAG 和导入导出。
5. [运维与排障](operations.md)：备份恢复、升级回退、多账号与集群边界。
6. [开发与验证](development.md)：工具链、测试门禁和文档维护。

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 任务 | Task | 一个插件动作及其配置，例如脚本或 SQL |
| 作业 | Job | 任务/子作业组成的 DAG，以及节点间依赖 |
| 发布版本 | Published version | 保存时形成的版本；作业引用具体任务/子作业版本 |
| 调度 | Schedule | 何时触发哪个目标，与任务本身的启停分开 |
| 运行实例 | Run | 一次实际受理和执行，有独立状态、时间及日志 |
| 资源 | Resource | 数据库、文件、服务等连接配置 |
| 执行节点 | Worker | 实际执行任务的主机或容器，路径和解释器属于该节点 |

页面支持中文/英文、浅色/深色和显示时区切换。显示时区与调度业务时区是不同设置。任务保存不代表已经运行，启动平台也不会自动创建示例业务。
