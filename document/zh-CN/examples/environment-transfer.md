# 两个环境间配置迁移

[English](../../en/examples/environment-transfer.md) · [手册首页](../README.md)

**验证状态：本轮隔离环境实测，范围及待验项见下文。**

相关字段：[页面操作手册](../user-guide/README.md)。

## 准备、配置与执行

登记新的目标环境 B，独立账号、数据库、密钥、端口和资源；源 A 保持不动。先导出一个无副作用 SCRIPT，再扩展含资源和子作业的包。选择是否携带资源配置、调度和通知绑定；包不含凭据。

在 B 上传 .ijob.zip，先映射独立资源和渠道、补 B 的凭据，逐项检查差异后导入。核对导入后任务/作业/调度默认停用，检查版本和引用，再手动启用一个样例并验证。查看导入历史和报告，部分失败按记录继续，不盲目重复整包。结束保留 A/B 映射和报告；配置包迁移不等于数据库历史或秘密备份恢复。

## 本轮实测范围

本轮从 A 导出一个当前父/子作业及无副作用脚本，导入独立数据库、账号和密钥的 B。检查新对象默认停用和 VERIFIED；B 重启后重复导入全部复用原对象。手动启用一个脚本后执行成功，原计划校验变为 DRIFTED，符合有意修改的结果。另验证含数据库资源的包不包含源密码或加密信封，缺少目标秘密时计划为 BLOCKED；显式映射到新建只读账号、提供独立目标密码后导入并验证，资源 ID 重映射正确，启用后真实 SQL 查询成功。部分失败续传及目标并发冲突另验。

## 结束检查

保留输入、定义版本、触发/实例 ID、脱敏日志和目标核对结果。只停止本案例拥有的进程或调度；其他环境和历史证据不作为清理对象。
