# 按现象排障

[English](../../en/operations/troubleshooting.md) · [手册首页](../README.md)

| 现象 | 检查顺序 | 恢复后验证 |
| --- | --- | --- |
| 启动失败/超时 | Java 21 → home 权限 → 端口 → bootstrap/应用日志 → 数据库；超时不等于进程退出 | READY、登录、节点状态 |
| 配置不生效 | home 是否正确 → 重复键 → 命令行/环境覆盖 → 重启/重建 | 检查实际节点与一条小任务 |
| 登录失败 | STATIC/DATABASE → 实际访问节点 → 账号状态/强制改密 → 审计 | 全新会话、正确角色 |
| 受理后没有执行 | 触发记录 → 根实例 → Worker/分组/白名单 → 并发限制 | 匹配节点领取并产生结果 |
| 调度不触发 | 目标有效 → 单条/全局开关 → 时区/有效期/日历 → SCHEDULER | 预览和实际触发分别验证 |
| 文件/解释器不存在 | 执行节点或容器内部路径/挂载/账号权限 | 同节点小样例 |
| 数据写入重复 | 重试、恢复、错过补发与目标幂等键 | 核对目标系统，再决定重试 |
| 数据库恢复后受保护 | DB 健康、原密钥、兼容指纹、A 先就绪再 B | 受控重启，不清协调表 |

问题报告包含版本/源码或制品哈希、平台、时间、步骤、实例/触发 ID、脱敏错误、预期与实际。不要附完整私有配置、数据库、token 或口令。保留失败和重试证据；“未执行”和“失败”不能写成“通过”。
