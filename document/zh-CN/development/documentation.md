## 同步维护

中英文使用相同相对文件名，逐篇同步事实、命令、配置键、枚举和样例。页面顶部提供对方语言和手册首页链接。字段解释在页面/插件参考，案例链接参考并提供样例和结果，不复制两套相互漂移的规则。

完整配置事实在共享 `document/reference/configuration-review.json`；初始化检查器的 54 项来自 `user-settings.tsv`。新增属性须同步来源/默认值/分级、类型校验与双语说明。修改表后执行：

```sh
python tools/distribution/docs.py --write
python tools/distribution/docs.py --check
```

检查递归双语配对、语言切换、本地链接、截图文件和生成表；它不替代人工阅读、真实 UI 核对及外部系统验收。

## 真实截图

先登记隔离资源和合成数据，再运行场景。每种语言在真实页面切换语言后采集，使用浅色、1440×1000；等表单/代码编辑器/图表加载完成。截图不包含秘密或完整私有配置，不伪造成功状态。仓库共享截图索引记录源版本、页面、语言、文件哈希和验证类别；运行日志/凭据留在外部环境。

复制图到对应语言 images/manual，配替代文字、说明和可复制配置。真实截图里的样例路径/ID属于演练环境，正文使用占位路径并注明替换。只读配置预览不能写成已投递/已执行。
