# 候选交付与后续事项

[English](../../en/development/release-checklist.md) · [手册首页](../README.md)

## 本次交付检查

- 源码、manifest、制品哈希、文档和截图来源可追溯；新候选目录不覆盖旧交付。
- 双语目录/链接/配置表和仓库白名单、许可证扫描通过。
- 后端/Agent、前端与分发工具检查按实际报告列出通过、预期跳过和未执行。
- 安装、启停、改配置、样例、恢复证据对应具体平台和版本，不将一个平台结果套给全部平台。
- 新环境只停止本轮拥有的服务，原演示和历史数据保持原样。

## 后续优先级

1. 按实际用户部署优先级补齐 SSH/SFTP、S3、Kafka/RabbitMQ、邮件接收、Agent、Local JAR 的独立端到端案例证据；保留当前配置示例状态直到验证完成。
2. 深化增量水位、相同水位排序、SCD2、多表部分提交、复杂网关、事件审批和双环境导入的故障恢复案例。
3. 在目标生产环境落实 TLS、服务托管、容量、告警接收、备份 RPO/RTO 和多节点故障演练。
4. 公开发布前完成既有许可证来源、MySQL/Oracle 驱动分发条件、漏洞处置、SBOM/NOTICE 核对；单独决定是否公开。

当前 GitHub 与候选继续私密；本清单不触发公开发布、镜像推送或仓库可见性修改。
