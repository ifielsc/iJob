# 候选交付检查

[English](../../en/development/release-checklist.md) · [手册首页](../README.md)

本清单适用于 iJob 1.0.0 的当前候选。公开仓库、发布资产与官网部署分别授权；完成本地检查不自动触发任何公开操作。旧阶段计划和历史验收记录保留在维护工作区，不作为当前待办或当前候选已通过的依据。

## 源码与内容

- 核对实际候选与逐文件白名单；排除私有官网工程、运行数据、真实配置、秘密、缓存及生成报告。
- 扫描当前文件与拟公开的 Git 历史，核对图片来源；启发式扫描不证明不存在秘密。
- 同步中英文手册、发布说明、配置表与本地链接，清除已移除功能和旧候选的现行描述。
- 产品/Maven/前端保持 1.0.0，Local JAR 协议 1，正式数据库首次安装为 V1。旧库转换工具不属于当前模块或下载资产；历史 SQL 与兼容性测试保持可追溯。

## 下载资产与许可

- 对照[版本说明](../releases.md)的资产清单，逐项验证 ZIP/TAR 路径、文件哈希、启动入口与运行载荷。
- Native/Docker 绑定同一份独立源码 ZIP 与 source-manifest；SHA256SUMS.txt 必须对应实际下载字节。不同批次即使都叫 1.0.0，也不能混用哈希或测试结论。
- 自有 LICENSE、实际第三方组件 LICENSE/NOTICE、前端清单和镜像系统层资料与最终成品相符。
- MySQL Connector/J、Oracle JDBC/NLS 由用户自备，不嵌入成品；PostgreSQL、SQL Server、SQLite 驱动随包提供并保留告知。测试作用域依赖不等于运行时随包分发。
- 二进制下载同时免费提供匹配的 `ijob-1.0.0-third-party-sources.zip` 与校验值。该交付件包含适用组件对应源码、补丁和构建资料；应用源码 ZIP 或维护者本地缓存均不能替代它。

## 验证与已知限制

- 按实际报告区分本轮执行、按相同运行字节复用、预期跳过及未执行。构建中的 `-DskipTests` 不算测试通过。
- 2026-11-01 本地候选的已有证据：后端/Agent 1683 项通过、2 项真实消息专项条件跳过；前端单测 447、普通浏览器 560、生产浏览器 147 项通过；分发工具 39 项通过。OS 升级新增 12 项底层兼容、13 项 Docker 运行、9 组 Compose 配置和 4 项驱动加载检查。文档重组不会被记作重新运行上述测试。
- 最终提交的远端 CI、Full 真实后端浏览器集成及适用运行矩阵须分别核对证据，不能用轻量 CI 或 Basic 代替。未重跑的扩展系统/数据库/MQ/恢复矩阵维持原边界，不声明全部组合通过。
- 保留原始漏洞命中与适用性处置。当前镜像仍有 Ubuntu 系统包及 Spring/MyBatis 内嵌 OGNL 的已知扫描项，见[版本说明](../releases.md)；不声称零漏洞。
- 用户准备的原生宿主系统另行维护。镜像内系统包属于发行载荷，必须审查；镜像采用 Ubuntu 不限制原生安装只能使用 Ubuntu。

## 正式公开时再执行

冻结并审阅实际提交，核对该提交的 CI 和测试证据；按已确定的方案开放 GitHub Issues，并在仓库公开后启用、验证 GitHub Private vulnerability reporting 及安全通知订阅（不另设邮箱，添加 SECURITY.md 不会自动启用功能）；取得发布授权后上传完整资产及校验文件。再从收件人视角验证下载、哈希、第三方源码取得与手册入口，更新仍标注“下载未开放”的页面。域名与官网上线独立安排，不能用计划地址冒充已可用入口。
