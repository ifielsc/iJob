# 业务并发控制

[English](../../en/user-guide/concurrency.md) · [手册首页](../README.md)

## 入口与操作路径

并发管理；任务并发策略。页面动作随当前账号权限提供；先确认操作对象及环境。

## 配置和动作说明

| 字段/动作 | 用途与填写规则 |
| --- | --- |
| `插件限制` | 约束该插件并发；移除只取消这一层限制。 |
| `任务并发` | 本任务上限或本层不限制；保存不发布任务版本。 |
| `共享资源` | 名称/code/上限/启用；所有绑定资源必须同时拿到许可。 |
| `上限/活动实例/版本` | 上限 1–10000；活动实例不等于许可占用数，变更受后端保护和版本校验。 |

## 操作与结果核对

为两条测试任务绑定上限 1 的同一资源，观察排队后依次执行。停用仍被引用的资源会阻止领取许可；有活动工作时不能随意降限或改策略。保存结果不确定先读取最新值，明确重新应用后再保存。
