# 配置包导出、映射与导入

[English](../../en/user-guide/import-export.md) · [手册首页](../README.md)

## 入口与操作路径

任务/作业列表 → 导出所选/导入包。页面动作随当前账号权限提供；先确认操作对象及环境。

## 配置和动作说明

| 字段/动作 | 用途与填写规则 |
| --- | --- |
| `导出范围` | 最多选 100 个任务/作业，展开依赖最多 500；选择资源引用或配置，不含凭据。 |
| `调度/通知/并发` | 可选调度和通知绑定；任务并发策略随任务，插件全局策略不随包。 |
| `上传/映射` | 格式 1 的 .ijob.zip，最大 16 MiB；映射到已有或新建目标，补目标环境凭据。 |
| `差异确认/应用` | 逐项核对地址、资源和引用，再确认导入；导入任务/作业/调度默认停用。 |
| `记录/继续导入` | 查看本账号记录和完成对象；不确定结果先核实，不重复提交整个包。 |

## 操作与结果核对

跨环境练习使用新的目标环境，先映射只读资源再导入单个 SCRIPT，核验版本、参数和默认停用状态后手动启用运行。报告不含凭据；失败时按记录处理剩余项，不把部分完成写成整体成功。
