# 监控服务器与 Agent

[English](../../en/user-guide/resources-monitor.md) · [手册首页](../README.md)

## 入口与操作路径

资源 → 监控服务器。资源创建、修改、删除、连接测试及敏感详情需要 ADMIN；三个角色均可读取允许公开的概要。禁用资源或执行节点不可达时，任务仍不能正常使用该资源。 完整动作见[角色权限矩阵](users-audits.md)。

## 配置和动作说明

名称、资源标识、启用和说明见[通用资源字段](resources.md#通用资源字段)；保存、删除和秘密保留规则见[通用资源动作](resources.md#通用资源动作)。下表初始值指新建资源；编辑时载入已有非秘密值，秘密字段默认保持不变。

### Agent 连接

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| 协议（`protocol`） | 有初始值 | HTTP | 始终 | HTTP 或 HTTPS，必须与 Agent 地址的协议一致。 |
| Agent 地址（`endpoint`） | 必填 | 空 | 始终 | 最多 2048 个字符，可带基础路径；不含用户名、密码、查询参数、片段或首尾空白。 |
| Bearer Token（`token`） | 表单可空；启用 Agent 认证时须匹配 | 新建为空；编辑时保持不变 | 始终 | 最多 4096 个字符，不含换行或空字符；已配置 Token 覆盖 Authorization 请求头。可显式替换或清除。 |
| 连接超时 (ms)（`connectTimeout`） | 必填（有初始值） | 5000 | 始终 | 100–300000 的整数，以毫秒计。 |
| 读取超时 (ms)（`readTimeout`） | 必填（有初始值） | 10000 | 始终 | 100–300000 的整数，以毫秒计；监控任务的采集期限另行配置。 |

### 自定义请求头

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| 名称（`headers` 的键） | 每行必填 | 无请求头；新增行为空 | 自定义请求头表 | 最多 50 行，名称最多 256 个字符；使用合法 HTTP 头名称且不区分大小写去重。 |
| 值（`headers` 的值） | 每行填写或保留 | 新增行为空；已有行保持不变 | 自定义请求头表中存在该行 | 最多 4096 个字符，不含控制字符；保存后不回显，删除整行移除。 |

### 服务端信息

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| 操作系统（`osType`） | 可选 | 未选择 | 始终 | 可选 LINUX、WINDOWS、MACOS，允许清空；记录真实目标系统，不能据此推断 Agent 已安装或兼容。 |
| Agent 版本（`agentVersion`） | 可选 | 空 | 始终 | 最多 64 个字符，记录真实版本；不替代与 Agent 的连接检查。 |

### 监控资源动作

| 动作 | 可用角色 | 可用条件 | 结果 |
| --- | --- | --- | --- |
| 添加请求头 | ADMIN | 编辑表单可写 | 新增一行名称和值，保存后生效。 |
| 移除 | ADMIN | 对应请求头行存在且表单可写 | 删除该行；保存时移除请求头。 |
| 测试已保存配置 | ADMIN | 编辑已有且已启用的资源；当前没有进行中的请求或未明确写入结果 | 从 API 节点使用已保存配置请求 Agent ping，不采集指标；表单草稿不会用于测试。 |
| 连接测试 | ADMIN | 列表中资源已保存并启用 | 执行同样的已保存配置 ping 检查，不等于监控任务采集成功。 |

## 操作与结果核对

先部署[独立 Agent](../configuration/deployment-agent.md)，测试连接和采集；核对指标时间与状态，再配置 [SERVER_MONITOR](plugins/server-monitor.md) 规则。Agent 不承担调度 Worker 职责。
