# 日历规则与例外

[English](../../en/user-guide/calendars.md) · [手册首页](../README.md)

## 入口与操作路径

日历 → 新增/编辑。页面动作随当前账号权限提供；先确认操作对象及环境。

## 配置和动作说明

| 字段/动作 | 用途与填写规则 |
| --- | --- |
| `名称/说明` | 描述适用业务周期，例如 docs-business-days。 |
| `规则与日期例外` | 配置工作日/排除日期等页面支持规则；例外应使用业务时区日期。 |
| `调度关联` | 保存日历后在调度选择；日历本身不创建任务触发。 |
| `预览验证` | 分别核验普通工作日、周末、例外日期和边界时间。 |

## 操作与结果核对

为示例调度排除一个未来日期，在调度预览中查看允许/排除结果。修改共享日历前核对引用调度；日历过滤与错过补发共同作用，应测试停机恢复窗口。
