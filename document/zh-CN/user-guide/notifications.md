# 邮件通道、规则与发送记录

[English](../../en/user-guide/notifications.md) · [手册首页](../README.md)

## 入口与操作路径

通知中心 → 邮件通道/通知。邮件通道、通知配置和投递详情由 ADMIN 管理和查看。OPERATOR、VIEWER 不具备配置写入或敏感详情读取权限，相关动作不可用。 完整动作见[角色权限矩阵](users-audits.md)。

## 配置和动作说明

页面没有独立的“选择通知模板/语言”字段；预览使用后台通知语言、时区及实际模板。机器人渠道的凭据按保留、替换、清除规则处理。

### 邮件通道字段

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| 通道名称 | 必填 | 空 | 始终 | 供通知配置选择的名称。 |
| SMTP 服务器 | 必填 | 空 | 始终 | 邮箱服务提供的 SMTP 主机。 |
| 端口 | 必填 | 465 | 始终 | 1–65535，应与连接加密方式匹配。 |
| 连接加密 | 有初始值 | SSL / TLS | 始终 | 选择不加密、STARTTLS 或 SSL / TLS。 |
| SMTP 身份认证 | 有初始值 | 开启 | 始终 | 决定是否使用用户名与授权码登录。 |
| 登录邮箱 / 用户名 | 必填 | 空 | 开启 SMTP 身份认证 | SMTP 登录账号。 |
| 授权码 / 应用密码 | 新建或更换主机/账号时必填 | 空 | 开启 SMTP 身份认证 | 已有值不回显；主机与账号未改时留空保留，填写新值替换。 |
| 默认发件地址 | 必填 | 空 | 始终 | 有效的发件邮箱地址。 |
| 启用 | 有初始值 | 开启 | 始终 | 停用通道后，引用它的待发送通知也不能发送。 |

### 通知配置与绑定

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| 名称 | 必填 | 空 | 通知配置 | 业务可识别的通知配置名。 |
| 类型 | 必填 | 邮件 | 通知配置 | 选择实际渠道；机器人类型显示对应地址与提醒字段。 |
| 邮件通道 | 必填 | 空 | 类型为邮件 | 引用已配置的发件通道，不在通知配置中复制 SMTP 凭据。 |
| 收件人 | 必填 | 空 | 类型为邮件 | 每行一个地址或逗号分隔；需有效且不能重复。 |
| 抄送 | 可选 | 空 | 类型为邮件 | 不能与收件人重复。 |
| 通知配置 | 必填 | 空 | 任务/作业的通知绑定 | 选择已有配置，绑定不等于任务 PUSH。 |
| 通知策略 | 必填 | 失败时通知 | 任务/作业的通知绑定 | 不通知、成功时通知、失败时通知或始终通知；失败包括超时。 |

### 操作与结果

| 动作 | 可用角色 | 可用条件 | 结果 |
| --- | --- | --- | --- |
| 连接检查 | ADMIN | 邮件通道已保存 | 连接 SMTP 并验证认证，不发送邮件。 |
| 预览内容 | ADMIN | 通知配置草稿有效，预览接口可用 | 使用真实发送模板渲染样例，不发送消息；语言和时区采用后台通知设置。 |
| 保存 | ADMIN | 配置或绑定有效，没有待核实的写入结果 | 保存配置或绑定，不立即发送；绑定独立于定义版本。 |
| 发送记录 | ADMIN | 可读取敏感投递详情 | 区分待处理、发送失败、重试与已发送；渠道确认不等于收件人已阅读。 |

## 操作与结果核对

演练使用专属测试收件箱或本地接收器。预览不发送，配置保存不证明投递。没有实际接收证据时只记为配置/预览验证。检查通道实现开关、规则启用、绑定和发送错误后再重试。
