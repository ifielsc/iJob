# 邮件通道、规则与发送记录

[English](../../en/user-guide/notifications.md) · [手册首页](../README.md)

## 入口与操作路径

通知中心 → 邮件通道/通知。页面动作随当前账号权限提供；先确认操作对象及环境。

## 配置和动作说明

| 字段/动作 | 用途与填写规则 |
| --- | --- |
| `邮件通道` | SMTP 主机/端口、认证和 TLS 配置归通道，密码按秘密规则保存。 |
| `通知规则与模板` | 选择通道、收件对象、事件条件和模板/语言；先预览渲染内容。 |
| `任务/作业绑定` | 绑定决定哪些运行事件使用规则，不等于任务 PUSH。 |
| `发送记录` | 区分待发送、失败、重试和成功；成功受渠道返回语义限制。 |

## 操作与结果核对

演练使用专属测试收件箱或本地接收器。预览不发送，配置保存不证明投递。没有实际接收证据时只记为配置/预览验证。检查通道实现开关、规则启用、绑定和发送错误后再重试。
