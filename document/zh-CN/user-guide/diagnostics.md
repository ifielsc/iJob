# 运行诊断与健康

[English](../../en/user-guide/diagnostics.md) · [手册首页](../README.md)

## 入口与操作路径

诊断；工作区节点详情。页面动作随当前账号权限提供；先确认操作对象及环境。

## 配置和动作说明

| 字段/动作 | 用途与填写规则 |
| --- | --- |
| `节点与组件状态` | 区分在线、数据新鲜度、角色和扫描状态。 |
| `队列与容量` | 等待、在途、线程/连接等指标按实际可用数据判断，不以未知代替 0。 |
| `错误上下文` | 关联时间、节点、触发/实例 ID 与日志，不复制秘密配置。 |

## 操作与结果核对

先用正常 docs-hello 建立基线，再查看预期失败样例的错误链路。诊断页用于定位，不替代业务目标系统核对。恢复数据库或变更节点时遵循[排障流程](../operations/troubleshooting.md)。
