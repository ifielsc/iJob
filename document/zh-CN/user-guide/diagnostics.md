# 运行诊断与健康

[English](../../en/user-guide/diagnostics.md) · [手册首页](../README.md)

## 入口与操作路径

诊断；工作区节点详情。三个角色均可查看诊断概要；诊断开关属于部署配置，页面不会向普通查看者授予服务器配置权限。 完整动作见[角色权限矩阵](users-audits.md)。

## 配置和动作说明

运行诊断与节点状态是不同页面。诊断开关属于部署配置；查看页面不赋予服务器配置修改权限。

### 运行诊断信息

| 页面显示 | 含义 | 出现条件 |
| --- | --- | --- |
| 租约已到期 | 工作项仍为 CLAIMED，租约截止不晚于本次数据库观察时间。 | 始终 |
| 队列等待较久 | READY/RETRY_WAIT 项超过配置的等待阈值；命中不代表已有符合路由的 Worker。 | 始终 |
| 根运行超期 | 根实例超过期限仍处于非终态，子实例和终态不在此类。 | 始终 |
| 命令待收尾 | 命令已到期且仍为 PENDING/PROCESSING。 | 始终 |
| 判断依据 | 关联当前状态、目标标识和时间，不单独据此认定 Worker 离线。 | 始终 |
| 节点与组件状态 | 在节点/运行状态页面查看角色、在线与采样新鲜度；未知不当作 0。 | 节点/运行状态页面 |
| 队列与容量 | 按实际采集的等待、在途、线程与连接指标判断；无数据不代表没有负载。 | 节点/运行状态页面 |

### 操作

| 动作 | 可用角色 | 可用条件 | 结果 |
| --- | --- | --- | --- |
| 刷新检查 | ADMIN / OPERATOR / VIEWER | 具有概要读取权限，检查条件有效 | 读取新的诊断事实，不自动停止或重试任务。 |
| 查看证据 | ADMIN / OPERATOR / VIEWER | 当前检查存在命中记录 | 查看判断时间与关联对象；需要日志时转到运行详情，日志需 ADMIN。 |
| 查看根运行 | ADMIN / OPERATOR / VIEWER | 证据包含根实例引用 | 核对实时状态与后续变化；诊断快照不会替代运行结果。 |

## 操作与结果核对

先用正常 docs-hello 建立基线，再查看预期失败样例的错误链路。诊断页用于定位，不替代业务目标系统核对。恢复数据库或变更节点时遵循[排障流程](../operations/troubleshooting.md)。
