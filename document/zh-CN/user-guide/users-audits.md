# 用户、权限与审计

[English](../../en/user-guide/users-audits.md) · [手册首页](../README.md)

## 入口与操作路径

系统管理 → 用户/操作审计。页面动作随当前账号权限提供；先确认操作对象及环境。

## 配置和动作说明

| 字段/动作 | 用途与填写规则 |
| --- | --- |
| `ADMIN / OPERATOR / VIEWER` | 业务账号角色，不同于 API/WORKER 等节点角色；按页面和接口权限控制动作。 |
| `账号状态与密码` | DATABASE 模式维护用户、启停和改密；保留启用管理员。STATIC 账号从私有配置读取。 |
| `审计过滤` | 按操作人、动作、目标、时间和结果查询，敏感信息按脱敏契约显示。 |

## 操作与结果核对

先读[账号模式](../operations/accounts.md)，确认当前模式是否提供用户管理入口。管理员新增普通测试账号后，用独立会话核验可见/可操作范围，再查看审计。审计证明平台操作记录，不代表外部事务已回滚或完成。
