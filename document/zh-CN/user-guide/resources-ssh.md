# SSH 资源与主机信任

[English](../../en/user-guide/resources-ssh.md) · [手册首页](../README.md)

## 入口与操作路径

资源 → SSH 资源。资源创建、修改、删除、连接测试及敏感详情需要 ADMIN；三个角色均可读取允许公开的概要。禁用资源或执行节点不可达时，任务仍不能正常使用该资源。 完整动作见[角色权限矩阵](users-audits.md)。

## 配置和动作说明

名称、资源标识、启用和说明见[通用资源字段](resources.md#通用资源字段)；保存、删除和秘密保留规则见[通用资源动作](resources.md#通用资源动作)。下表初始值指新建资源；编辑时载入已有非秘密值，秘密字段默认保持不变。

### 连接与身份

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| 主机（`host`） | 必填 | 空 | 始终 | 目标主机名或地址，不含协议、路径或用户名；最多 255 个字符。 |
| 端口（`port`） | 必填（有初始值） | 22 | 始终 | 1–65535 的整数，按目标实际监听端口填写。 |
| 用户名（`username`） | 必填 | 空 | 始终 | 最多 128 个字符，使用独立受限账号。 |
| 认证方式 | 有初始值 | 密码（PASSWORD） | 新建资源 | 选择密码或私钥；编辑已有资源时分别管理已存凭据，不显示此选择。 |
| 密码（`password`） | 密码认证必填；编辑时与私钥至少保留一个 | 新建为空；编辑时保持不变 | 新建时选择密码；编辑已有资源 | 最多 4096 个字符，不回显旧值。 |
| 私钥文件路径（`privateKey`） | 私钥认证必填；编辑时与密码至少保留一个 | 新建为空；编辑时保持不变 | 新建时选择私钥；编辑已有资源 | 执行 Worker 可读的本地文件路径，不是 PEM 内容或远程路径；连接测试所在 API 节点也须能读取该路径。 |
| 私钥口令（`passphrase`） | 可选；提供时须有私钥路径 | 新建为空；编辑时保持不变 | 新建时选择私钥；编辑已有资源 | 解锁加密私钥的口令，最多 4096 个字符。 |
| 主机校验方式（`hostKeyVerification`） | 有初始值 | 平台管理（MANAGED） | 高级配置展开时 | 可切换为手动指定 known_hosts 文件（KNOWN_HOSTS）；不提供跳过主机校验的选项。 |
| 主机身份（`hostKey`） | MANAGED 模式须确认 | 未确认 | MANAGED 模式 | 获取后显示密钥类型和 SHA256 指纹；核对可信来源后确认。由平台保存主机公钥，不是私钥输入框。 |
| known_hosts 文件路径（`knownHosts`） | 必填 | 空 | 高级配置中选择 KNOWN_HOSTS | 最多 2048 个字符；执行 Worker 与做连接测试的 API 节点分别需要可读取的文件。 |
| 连接超时（毫秒）（`connectTimeout`） | 必填（有初始值） | 30000 | 高级配置展开时 | 100–300000 的整数；与 SCRIPT 执行超时分别配置。 |

### SSH 资源动作

| 动作 | 可用角色 | 可用条件 | 结果 |
| --- | --- | --- | --- |
| 获取并核对指纹 | ADMIN | 选择 MANAGED；主机、端口和连接超时有效 | 连接目标获取指纹，不发送认证密码；确认可信后存入当前草稿，保存资源后生效。 |
| 重新核对指纹 | ADMIN | 已确认主机身份，表单可写 | 再次获取指纹；变化时提示旧指纹，核实后才信任新密钥。 |
| 连接测试 | ADMIN | 资源已保存并启用；信任与认证配置有效 | 从 API 节点连接 SSH 并执行 `true`；私钥和 known_hosts 文件须在该节点可读。 |

## 操作与结果核对

测试连接后，用 SCRIPT/SSH 执行 `echo hello-ijob`，确认实际远程用户、目录和解释器。主机密钥改变先核对原因，不通过关闭校验消除报错。SFTP 文件资源也需独立的路径/权限与信任配置。
