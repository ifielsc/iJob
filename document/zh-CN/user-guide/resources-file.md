# LOCAL、FTP、SFTP 与 S3 文件资源

[English](../../en/user-guide/resources-file.md) · [手册首页](../README.md)

## 入口与操作路径

资源 → 文件资源。资源创建、修改、删除、连接测试及敏感详情需要 ADMIN；三个角色均可读取允许公开的概要。禁用资源或执行节点不可达时，任务仍不能正常使用该资源。 完整动作见[角色权限矩阵](users-audits.md)。

## 配置和动作说明

名称、资源标识、启用和说明见[通用资源字段](resources.md#通用资源字段)；保存、删除和秘密保留规则见[通用资源动作](resources.md#通用资源动作)。下表初始值指新建资源；编辑时载入已有非秘密值，秘密字段默认保持不变。

### 协议与根目录

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| 文件协议（`protocol`） | 必填 | LOCAL | 始终 | 可选 LOCAL、FTP、SFTP、S3_COMPATIBLE；切换协议时显示对应配置。 |
| 根目录 / 根前缀（`basePath`） | 必填 | LOCAL 为空；首次切换其他协议为 `/` | 始终 | 最多 2048 个字符。LOCAL 是执行节点绝对目录；FTP/SFTP 是账号可见远端目录；S3 是对象根前缀。任务路径基于此根，不是浏览器上传目录。 |
| 连接超时（毫秒）（`timeout`） | 必填（有初始值） | 30000 | 始终 | 100–300000 的整数；与文件传输任务自身超时分开。 |

### FTP 与 SFTP

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| 主机（`host`） | 必填 | 空 | FTP 或 SFTP | 目标主机名或地址，不含协议、路径或用户名；最多 255 个字符。 |
| 端口（`port`） | 必填（有初始值） | 首次切换 FTP 为 21；SFTP 为 22 | FTP 或 SFTP | 1–65535 的整数，按目标实际监听端口填写。 |
| 用户名（`username`） | 必填 | 空 | FTP 或 SFTP | 最多 128 个字符，使用独立受限账号。 |
| 认证方式 | 有初始值 | 密码（PASSWORD） | 新建 SFTP 资源 | 选择密码或私钥；编辑已有资源时分别管理已存凭据，不显示此选择。 |
| 密码（`password`） | FTP 必填；SFTP 与私钥至少保留一个 | 新建为空；编辑时保持不变 | FTP；新建 SFTP 的密码认证；编辑已有 SFTP | 最多 4096 个字符，不回显旧值。 |
| 私钥文件路径（`privateKey`） | 私钥认证必填；编辑时与密码至少保留一个 | 新建为空；编辑时保持不变 | 新建 SFTP 的私钥认证；编辑已有 SFTP | 执行 Worker 可读的本地文件路径，不是 PEM 内容或远程路径；连接测试所在 API 节点也须能读取该路径。 |
| 私钥口令（`passphrase`） | 可选；提供时须有私钥路径 | 新建为空；编辑时保持不变 | 新建 SFTP 的私钥认证；编辑已有 SFTP | 解锁加密私钥的口令，最多 4096 个字符。 |
| 主机校验方式（`hostKeyVerification`） | 有初始值 | 平台管理（MANAGED） | SFTP | 可切换为手动指定 known_hosts 文件（KNOWN_HOSTS）；不提供跳过主机校验的选项。 |
| 主机身份（`hostKey`） | MANAGED 模式须确认 | 未确认 | SFTP 且为 MANAGED | 获取后显示密钥类型和 SHA256 指纹；核对可信来源后确认。由平台保存主机公钥，不是私钥输入框。 |
| known_hosts 文件路径（`knownHosts`） | 必填 | 空 | SFTP 且为 KNOWN_HOSTS | 最多 2048 个字符；执行 Worker 与做连接测试的 API 节点分别需要可读取的文件。 |

### S3 兼容对象存储

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| Endpoint（可选）（`endpoint`） | 可选；自建兼容服务按实际填写 | 空 | S3_COMPATIBLE | 服务 endpoint，最多 2048 个字符；是否需要显式地址取决于所用服务。 |
| 区域（`region`） | 必填 | 空 | S3_COMPATIBLE | 最多 128 个字符，与目标服务的签名区域一致。 |
| 存储桶（`bucket`） | 必填 | 空 | S3_COMPATIBLE | 最多 255 个字符，填写已授权的桶。 |
| Access Key（`accessKey`） | 必填，可保留已有值 | 新建为空；编辑时保持不变 | S3_COMPATIBLE | 最多 512 个字符，保存后不回显；不提供直接清除入口。 |
| Secret Key（`secretKey`） | 必填，可保留已有值 | 新建为空；编辑时保持不变 | S3_COMPATIBLE | 最多 4096 个字符，保存后不回显；替换时填写完整新值。 |
| Session Token（可选）（`sessionToken`） | 可选；临时凭据需要时填写 | 新建为空；编辑时保持不变 | S3_COMPATIBLE | 最多 65535 个字符，与访问密钥配套；可显式清除。 |
| 路径风格访问（`pathStyleAccess`） | 有初始值 | 开启 | S3_COMPATIBLE | 按对象服务兼容性选择路径风格或虚拟主机风格。 |

### 文件资源动作

| 动作 | 可用角色 | 可用条件 | 结果 |
| --- | --- | --- | --- |
| 浏览根目录 | ADMIN | 表单可写且无未明确的写入结果；远端资源已填根目录，SFTP 已确认主机信任 | 浏览可访问目录并回填根路径。LOCAL 从 API 节点允许浏览的根开始。这里不是浏览器所在电脑的本地磁盘；执行时仍以 Worker 的文件系统和权限为准。 |
| 获取并核对指纹 | ADMIN | SFTP 选择 MANAGED；主机、端口和连接超时有效 | 连接目标获取指纹，不发送认证密码；确认可信后存入当前草稿，保存资源后生效。 |
| 重新核对指纹 | ADMIN | 已确认主机身份，表单可写 | 再次获取指纹；变化时提示旧指纹，核实后才信任新密钥。 |
| 连接测试 | ADMIN | 资源已保存并启用 | 使用已保存配置列举资源根目录，不传输文件；测试节点与 Worker 的路径和访问条件可能不同。 |

## 操作与结果核对

先在资源根准备 orders.csv，再测试列目录/读取，最后对独立目标做写入验证。浏览器允许根列表不限制脚本的所有磁盘访问。不要把平台 runtime 或 secrets 当作传输源。
