# 事件审批与处理记录

[English](../../en/user-guide/events.md) · [手册首页](../README.md)

## 入口与操作路径

审批。审批需要 ADMIN 或 OPERATOR、当前账号在允许操作人名单内，且等待记录尚未处理或过期。VIEWER 不能审批；事件发布和绑定配置需要 ADMIN。 完整动作见[角色权限矩阵](users-audits.md)。

## 配置和动作说明

允许操作人在 EVENT 任务的审批等待配置中维护，不是本审批页的可编辑字段。普通事件等待不提供人工审批动作。

### 审批信息

| 页面显示 | 含义 | 出现条件 |
| --- | --- | --- |
| 状态 | 待审批、已通过、已拒绝、已撤回、已超时等分别表示不同结果。 | 始终 |
| 当前实例 ID | 定位当前审批节点，操作前核对来源。 | 始终 |
| 根实例 ID | 定位所属完整业务运行。 | 始终 |
| 等待开始 | 节点进入等待的时间。 | 始终 |
| 截止时间 | 是否到期及最终状态以后台为准；未设置期限时显示不限时。 | 始终 |

### 处理字段

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| 处理意见（可选） | 可选 | 空 | 可处理的审批详情 | 最多 500 个字符，记录决定理由。 |

### 操作

| 动作 | 可用角色 | 可用条件 | 结果 |
| --- | --- | --- | --- |
| 通过 | ADMIN / OPERATOR | 账号在允许操作人名单内；审批仍为待审批且未到期 | 当前审批节点成功，后续按作业策略继续。 |
| 拒绝 | ADMIN / OPERATOR | 账号在允许操作人名单内；审批仍为待审批且未到期 | 当前审批节点失败，后续按作业策略处理。 |
| 刷新状态 | ADMIN / OPERATOR | 当前账户可访问该记录 | 核实后台实际结果；请求结果不明时先核实，不自动重复决定。 |

## 操作与结果核对

使用[事件案例](../examples/events-and-approval.md)建立专属等待，先确认等待记录，再处理并观察原实例恢复。重复提交或过期审批不能视为新成功；输入和审批记录按权限查看。
