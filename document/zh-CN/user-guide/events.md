# 事件审批与处理记录

[English](../../en/user-guide/events.md) · [手册首页](../README.md)

## 入口与操作路径

审批。页面动作随当前账号权限提供；先确认操作对象及环境。

## 配置和动作说明

| 字段/动作 | 用途与填写规则 |
| --- | --- |
| `待处理/已处理` | 按状态、业务关联和时间定位等待；先核对来源实例。 |
| `允许操作人` | 只有满足权限及 allowedOperatorIds 约束的身份可处理。 |
| `批准/拒绝与说明` | 操作会影响真实等待及后续依赖；记录理由并核对终态。 |

## 操作与结果核对

使用[事件案例](../examples/events-and-approval.md)建立专属等待，先确认等待记录，再处理并观察原实例恢复。重复提交或过期审批不能视为新成功；输入和审批记录按权限查看。
