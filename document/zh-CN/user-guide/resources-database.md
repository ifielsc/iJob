# 数据库资源

[English](../../en/user-guide/resources-database.md) · [手册首页](../README.md)

## 入口与操作路径

资源 → 数据库资源。资源创建、修改、删除、连接测试及敏感详情需要 ADMIN；三个角色均可读取允许公开的概要。禁用资源或执行节点不可达时，任务仍不能正常使用该资源。 完整动作见[角色权限矩阵](users-audits.md)。

## 配置和动作说明

名称、资源标识、启用和说明见[通用资源字段](resources.md#通用资源字段)；保存、删除和秘密保留规则见[通用资源动作](resources.md#通用资源动作)。下表初始值指新建资源；编辑时载入已有非秘密值，秘密字段默认保持不变。

### 连接配置

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| 数据库类型（`dbType`） | 必填 | 未选择 | 始终 | MySQL、PostgreSQL、Oracle、SQL Server；技术值为 MYSQL、POSTGRESQL、ORACLE、SQLSERVER。选择与业务数据库和 JDBC URL 匹配的类型。 |
| JDBC URL（`jdbcUrl`） | 必填 | 空 | 始终 | 使用所选类型的 JDBC 地址，最多 2048 个字符；不能在 URL 中加入 password、passwd 或 pwd 参数。 |
| 用户名（`username`） | 必填 | 空 | 始终 | 最多 128 个字符；使用仅具备所需读写权限的独立业务账号。 |
| 密码（`password`） | 表单可空；以目标认证要求为准 | 新建为空；编辑时保持不变 | 始终 | 最多 4096 个字符，已有密码不回显；需要移除时显式选择清除，不提交空的替换值。 |
| Schema（`schema`） | 可选 | 空 | 高级配置展开时 | 最多 128 个字符，按目标数据库的 schema 填写。 |

### 数据库资源动作

| 动作 | 可用角色 | 可用条件 | 结果 |
| --- | --- | --- | --- |
| 切换数据库类型 | ADMIN | 编辑表单中选择其他类型并确认 | 首次切换到该类型时重新填写连接地址、用户名和密码；本次编辑已填写过的类型会恢复其草稿。取消则保留当前输入。 |
| 连接测试 | ADMIN | 资源已保存、启用；API 节点可访问目标 | 检查已保存数据库连接；不代替任务 SQL 和业务权限核对。 |

## 操作与结果核对

PostgreSQL 示例 URL：`jdbc:postgresql://127.0.0.1:15432/docs_source`，替换本环境端口。先测试连接，再执行只读 SELECT。平台 SQLite 不在这个资源列表；ETL 的 SQLite 文件读取在 FILE 源配置。
