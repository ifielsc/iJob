# 服务器监控

[English](../../../en/user-guide/plugins/server-monitor.md) · [手册首页](../../README.md)

适用版本：**1.0.0**。任务 → 新增/编辑 → 插件 `SERVER_MONITOR`。

## 入口与准备

使用 ADMIN 创建、配置和保存任务；ADMIN 或 OPERATOR 可以执行已发布定义，详细日志和输入输出变量由 ADMIN 查看。资源必须启用并可被执行节点访问。任务公共超时、重试和版本规则见[任务](../tasks.md)，角色动作见[权限矩阵](../users-audits.md)。

## 字段说明

“默认值”指 **1.0.0 新建表单的初始值**；空表示尚未填写，不表示必填项可以省略。显示条件决定当前分支中是否出现字段。“条件必填”只在对应分支启用时要求填写。

### 采集

| 字段 | 是否必填 | 默认值 | 显示条件 | 作用范围 |
| --- | --- | --- | --- | --- |
| 监控服务器 | 必填 | 无 | 始终 | 当前任务版本 |
| 采集项目 | 至少一项 | ["CPU"] | 始终 | 当前任务版本 |

- **监控服务器**：提供被监控服务器的监控 Agent 连接。
- **采集项目**：CPU/MEMORY/DISK/NETWORK/APPLICATION，不重复。

### 应用采集

| 字段 | 是否必填 | 默认值 | 显示条件 | 作用范围 |
| --- | --- | --- | --- | --- |
| 应用名称 | 必填 | 空 | 采集 APPLICATION | 当前任务版本 |
| 匹配方式 | 选择 | PROCESS_NAME | 采集 APPLICATION | 当前任务版本 |
| 匹配值 | 必填 | 空 | 采集 APPLICATION | 当前任务版本 |
| 必须运行 | 选择 | true | 采集 APPLICATION | 当前任务版本 |
| 允许多个进程 | 选择 | false | 采集 APPLICATION | 当前任务版本 |

- **应用名称**：监控配置中的唯一应用名，最多64个应用；名称最多128字符。
- **匹配方式**：选择PROCESS_NAME、COMMAND、PID或REGEX匹配进程。
- **匹配值**：填写所选匹配方式需要的值；PID必须是正整数，正则最长256字符。
- **必须运行**：指定该应用是否必须处于运行状态。
- **允许多个进程**：指定是否允许多个进程同时匹配该应用。

- **严重**：严重阈值不得低于警告。
- **警告**：网络单位 B/s；CPU/内存/磁盘为百分比。
- **严重**：严重阈值不得低于警告。
- **警告**：网络单位 B/s；CPU/内存/磁盘为百分比。

- **警告**：网络单位 B/s；CPU/内存/磁盘为百分比。

### 磁盘

| 字段 | 是否必填 | 默认值 | 显示条件 | 作用范围 |
| --- | --- | --- | --- | --- |
| 磁盘路径覆盖 | 可选 | 空 | 采集 DISK 且启用磁盘规则 | 当前任务版本 |

- **磁盘路径覆盖**：按完整路径匹配；未匹配时使用默认阈值。

### 应用阈值

| 字段 | 是否必填 | 默认值 | 显示条件 | 作用范围 |
| --- | --- | --- | --- | --- |
| CPU (%) | 条件必填 | 无 | 启用对应应用监控 | 当前任务版本 |
| 内存 (MiB) | 条件必填 | 无 | 启用对应应用监控 | 当前任务版本 |

- **CPU (%)**：应用名须对应采集配置；CPU 为百分比，内存 MiB。
- **内存 (MiB)**：应用名须对应采集配置；CPU 为百分比，内存 MiB。

### 告警

| 字段 | 是否必填 | 默认值 | 显示条件 | 作用范围 |
| --- | --- | --- | --- | --- |
| 发送监控告警 | 可选 | false | 始终 | 当前任务版本 |
| 通知配置 | 条件必填 | 无 | 发送监控告警 | 当前任务版本 |

- **发送监控告警**：开启后按规则结果发送监控告警。
- **通知配置**：指定接收监控告警的通知配置。

## 使用边界

- 至少启用一个有效规则；只有采集到的项目可配置其规则。
- 不支持恢复通知和跨次告警去重，notify.recovery=true 被拒绝。
- 首次数率采样可能为 0；指标缺失与实际 0 不同。

## 典型配置：采集 CPU 与内存

按下表填写界面，资源名称需替换为自己的已启用资源。这是配置说明，不是可直接导入的 JSON。完整数据准备与执行步骤见本节末尾教程。

准备已配置认证且Worker可达的监控Agent；阈值结果取决于实际指标，不保证本例一定健康。

| 配置项 | 填写内容 |
| --- | --- |
| 监控服务器 | 已配置的教程Agent资源 |
| 采集项目 | ["CPU","MEMORY"] |
| 启用CPU阈值 | true |
| CPU警告阈值 | 80 |
| CPU严重阈值 | 95 |
| 发送监控告警 | false |

**预期结果：** 时间与指标新鲜有效；阈值结果可解释；告警不直接等于任务执行失败。

[跟做完整教程](../../examples/monitoring.md)。保存定义后再手动执行；实例状态与业务结果分别核对。
