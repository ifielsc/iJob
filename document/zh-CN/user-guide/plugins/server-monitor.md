# 服务器监控

[English](../../../en/user-guide/plugins/server-monitor.md) · [手册首页](../../README.md)

## 入口与前提

任务 → 新增/编辑 → 插件 `SERVER_MONITOR`。先准备字段表要求的资源、权限及执行节点依赖。任务公共超时、重试和发布规则见[任务](../tasks.md)。

## 字段与作用

| 页面字段/动作 | 用途与填写规则 |
| --- | --- |
| 监控服务器 | 选择监控服务器资源，Agent 地址和 token 在资源内维护。 |
| 采集项目、应用采集 | 选择实际需要的系统指标与应用采集配置，必须由 Agent 支持。 |
| CPU、内存、磁盘、网络及应用阈值规则 | 按采集指标配置阈值和应用规则，注意单位、路径和缺失指标。 |
| 发送监控告警、通知配置 | 选择是否发送监控告警及通知配置；当前不支持恢复通知和跨次告警去重。首次演练关闭通知。 |

## 最小样例与核对

先准备上表的独立测试资源，按页面逐项填写；保存后手动执行，再按下文核对实例、输出与目标系统。保存本身不会执行。

| 配置项 | 填写内容 |
| --- | --- |
| 监控服务器 | 选择专属测试 Agent 资源 |
| 采集项目 | CPU、内存 |
| CPU 使用率 → 启用 / 警告 / 严重 | 开启 / 80 / 95（百分比） |
| 发送监控告警 | 首次演练关闭 |

测试连接后采集一次，核对时间、新鲜度、指标和规则结果。采集失败、指标缺失与阈值告警不同，不能把不可用显示成 0。再用独立规则样例核对异常和恢复后的采集结果；恢复正常不会自动发出恢复通知，通知发送需要单独证据。

示例中的资源、路径及对象名称需替换为本环境实际值；实际外部协议验收状态见[案例索引](../../examples.md)。

## 技术字段对照（按需查阅）

以下是保存配置中的键名，供开发或排障定位；不是需要粘贴的任务 JSON。自动核验的元数据不作为页面手工输入。

| 页面字段/分组 | 技术键名 |
| --- | --- |
| 监控服务器 | `resourceId` |
| 采集项目、应用采集 | `collect.items / collect.applications` |
| CPU、内存、磁盘、网络及应用阈值规则 | `rules.cpu / memory / disk / network / applications` |
| 发送监控告警、通知配置 | `notify.enabled / notify.notifyConfigId` |
