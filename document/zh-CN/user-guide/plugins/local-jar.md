# 可信 Local JAR 插件

[English](../../../en/user-guide/plugins/local-jar.md) · [手册首页](../../README.md)

适用版本：**1.0.0**。任务 → 新增/编辑 → 插件 `LOCAL_JAR`。

## 入口与准备

使用 ADMIN 创建、配置和保存任务；ADMIN 或 OPERATOR 可以执行已发布定义，详细日志和输入输出变量由 ADMIN 查看。资源必须启用并可被执行节点访问。任务公共超时、重试和版本规则见[任务](../tasks.md)，角色动作见[权限矩阵](../users-audits.md)。

## 字段说明

“默认值”指 **1.0.0 新建表单的初始值**；空表示尚未填写，不表示必填项可以省略。显示条件决定当前分支中是否出现字段。“条件必填”只在对应分支启用时要求填写。

### 制品与参数

| 字段 | 是否必填 | 默认值 | 显示条件 | 作用范围 |
| --- | --- | --- | --- | --- |
| JAR 文件名 | 必填 | 空 | 始终 | 当前任务版本 |
| SHA-256 校验值 | 必填 | 空 | 始终 | 当前任务版本 |
| 入口类 | 必填 | 空 | 始终 | 当前任务版本 |
| 业务参数 | 由扩展契约决定 | 空对象 | 始终 | 当前任务版本 |
| 文件大小 | 自动核验 | 无 | 保存后 | 当前任务版本 |
| 制品版本 | 自动核验 | 无 | 保存后 | 当前任务版本 |
| SPI 版本 | 自动核验 | 1 | 保存后 | 当前任务版本 |

- **JAR 文件名**：选择扩展目录中的实际 JAR 文件名，不包含路径。
- **SHA-256 校验值**：校验已审核 JAR 的实际字节内容。
- **入口类**：填写实现扩展接口的完整入口类名。
- **业务参数**：按扩展契约填写 JSON 业务参数；新建默认空对象，根类型可选择对象、数组、字符串、数字、布尔或 null。
- **文件大小**：由制品校验记录实际文件大小。
- **制品版本**：由制品元数据记录扩展实现版本。
- **SPI 版本**：由制品核验的接口协议版本，当前协议为 1。

## 使用边界

- 业务参数使用技术键userConfig。
- JAR 文件名不带路径；SHA-256 为 64 位十六进制。
- API 与 Worker 都需要同一经审核制品；页面不上传 JAR。
- 配置协议 1；宿主 SPI Maven 版本 1.0.0；最大配置 256 KiB，深度 64、节点 10000。
- 扩展不是不可信代码沙箱，不打包平台类。

## 典型配置：运行可信 HelloTask 扩展

按下表填写界面，资源名称需替换为自己的已启用资源。这是配置说明，不是可直接导入的 JSON。完整数据准备与执行步骤见本节末尾教程。

按链接教程编译实际HelloTask制品并部署到API和目标Worker，填写核对后的真实SHA-256；本例业务参数使用空对象。

| 配置项 | 填写内容 |
| --- | --- |
| JAR 文件名 | hello-job-1.0.0.jar |
| SHA-256 校验值 | 实际制品 SHA-256，不能使用占位值 |
| 入口类 | com.example.jobs.HelloTask |
| 业务参数 | {} |

**预期结果：** 使用下方教程编译的HelloTask时，实例SUCCESS，日志含hello-localjar，输出变量rows为数字3。

[跟做完整教程](../../examples/local-jar.md)。保存定义后再手动执行；实例状态与业务结果分别核对。

## 技术字段对照

以下键名用于导入配置、接口或排障。规则中的 `[]` 表示集合元素；不需要把这些键名填入界面标签。

| 类别 / 字段 | 技术键名 |
| --- | --- |
| 制品与参数 / JAR 文件名 | `jarFile` |
| 制品与参数 / SHA-256 校验值 | `sha256` |
| 制品与参数 / 入口类 | `entryClass` |
| 制品与参数 / 业务参数 | `userConfig` |
| 制品与参数 / 文件大小 | `jarSize` |
| 制品与参数 / 制品版本 | `implementationVersion` |
| 制品与参数 / SPI 版本 | `spiVersion` |
