# 接口调用

[English](../../../en/user-guide/plugins/api-call.md) · [手册首页](../../README.md)

## 入口与前提

任务 → 新增/编辑 → 插件 `API_CALL`。先准备字段表要求的资源、权限及执行节点依赖。任务公共超时、重试和发布规则见[任务](../tasks.md)。

## 字段与作用

| 页面字段/动作 | 用途与填写规则 |
| --- | --- |
| 服务资源、请求路径、请求方法 | 服务资源提供基础地址和认证；填写相对路径与方法，默认 POST，读取样例明确选 GET。 |
| 请求头、请求体、SOAP 配置 | 按协议填写请求头、请求体或 WebService 参数；已保存敏感头按保留/替换规则维护。 |
| 响应上限（字节） | 默认 1 MiB，限制读取响应体；不要为返回大文件无限增加。 |
| 响应变量提取、业务成功条件 | 提取器填写 variable 与 JSONPath expression；业务成功条件和 HTTP 状态分别核对。 |
| 远端停止（可选） | 仅在服务支持明确的远程取消协议时配置；停止本地等待不保证远端业务停止。 |

## 最小样例与核对

先准备上表的独立测试资源，按页面逐项填写；保存后手动执行，再按下文核对实例、输出与目标系统。保存本身不会执行。

| 配置项 | 填写内容 |
| --- | --- |
| 服务资源 | 选择专属测试 HTTP 服务 |
| 请求路径 | `/orders/summary` |
| 请求方法 | GET |
| 请求体 | 留空 |
| 响应变量提取 → 变量名 | `total` |
| 响应变量提取 → JSONPath | `$.total` |

先在页面选择真实测试服务资源。先测试连接，再调用只读接口，核对响应、提取变量及业务成功条件。HTTP 连接成功不等于业务成功；网络超时可能发生在远端已提交之后，重试前使用幂等键或查询结果。

当前 API_CALL 的 HTTP 错误状态和业务条件失败会结束为 FAILED，不因任务配置了重试次数而自动重发；请求超时结束为 TIMED_OUT。需要再次执行时，先核对远端结果，再手动触发。独立接收端已验证：503 后没有自动重发，手动重执行成功；两次使用相同幂等键和请求体的写入只产生一条业务记录。

示例中的资源、路径及对象名称需替换为本环境实际值；实际外部协议验收状态见[案例索引](../../examples.md)。

## 技术字段对照（按需查阅）

以下是保存配置中的键名，供开发或排障定位；不是需要粘贴的任务 JSON。自动核验的元数据不作为页面手工输入。

| 页面字段/分组 | 技术键名 |
| --- | --- |
| 服务资源、请求路径、请求方法 | `resourceId / path / method` |
| 请求头、请求体、SOAP 配置 | `headers / body / webService` |
| 响应上限（字节） | `maxResponseBytes` |
| 响应变量提取、业务成功条件 | `extractors / successCondition` |
| 远端停止（可选） | `remoteStop` |
