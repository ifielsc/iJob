# 资源配置与秘密字段

[English](../../en/user-guide/resources.md) · [手册首页](../README.md)

## 入口与操作路径

资源 → 对应资源类型。页面动作随当前账号权限提供；先确认操作对象及环境。

## 配置和动作说明

| 字段/动作 | 用途与填写规则 |
| --- | --- |
| `code / name / enabled / description` | 稳定资源标识、显示名称、启用与用途；任务引用资源 ID。 |
| `连接配置` | 按类型填写地址、协议、账号、根路径；网络从 API/Worker 所在环境验证。 |
| `秘密保留/替换/清除` | 编辑时不返回原秘密明文；保持未改以保留，输入新值替换，明确清除才删除。 |
| `测试连接` | 真实访问外部资源，需有权限；测试成功不代表业务 SQL/写入/消费权限齐备。 |

## 操作与结果核对

先创建独立资源，再在任务选择。资源被多个任务共享时，改地址或禁用会影响所有使用者；变更前检查引用。详见数据库、SSH、服务、文件、消息和监控分册。导出包不带凭据，目标环境需重新填写。
