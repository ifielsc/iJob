# 资源配置与秘密字段

[English](../../en/user-guide/resources.md) · [手册首页](../README.md)

## 入口与操作路径

资源 → 对应资源类型。资源创建、修改、删除、连接测试及敏感详情需要 ADMIN；三个角色均可读取允许公开的概要。禁用资源或执行节点不可达时，任务仍不能正常使用该资源。 完整动作见[角色权限矩阵](users-audits.md)。

## 配置和动作说明

连接字段按资源类型说明：[数据库](resources-database.md)、[服务](resources-service.md)、[文件](resources-file.md)、[SSH](resources-ssh.md)、[消息队列](resources-messaging.md)、[监控](resources-monitor.md)。初始值指新建资源，不是连接服务的默认配置。

### 通用资源字段

| 字段 | 是否必填 | 界面初始值 | 显示条件 | 说明 |
| --- | --- | --- | --- | --- |
| 名称（`name`） | 必填 | 空 | 始终 | 最多 128 个字符，用于列表、查询和任务选择。 |
| 资源标识（`code`） | 必填 | 自动生成 `res-` 加 UUID，可修改 | 始终 | 最多 128 个英文字母、数字、点、下划线或连字符；须唯一。任务保存的是资源 ID 引用。 |
| 启用（`enabled`） | 有初始值 | 开启 | 始终 | 停用后不能作为可用执行资源，列表连接测试也不可用；修改后保存生效。 |
| 说明（`description`） | 可选 | 空 | 始终；数据库与服务资源在高级配置中 | 最多 500 个字符，记录用途与目标环境，不填写秘密。 |

### 通用资源动作

以下为内置角色权限。账户仍须处于可用状态并完成要求的密码修改；请求处理中或写入结果尚不明确时，应先核对结果再继续操作。

| 动作 | 可用角色 | 可用条件 | 结果 |
| --- | --- | --- | --- |
| 查询 | ADMIN、OPERATOR、VIEWER | 可读取资源概要 | 按名称、启用状态筛选；不返回秘密明文。 |
| 查看详情 | ADMIN | 资源存在；具有敏感详情权限 | 展示配置和秘密是否已配置，不回显已保存秘密。 |
| 新建 | ADMIN | 可写入资源配置 | 打开新建表单，尚未保存也不会自动连接目标。 |
| 编辑 | ADMIN | 资源存在且可写入 | 载入表单；已保存秘密默认保持不变。 |
| 保存 | ADMIN | 必填、格式和认证条件通过校验；编辑已有资源时已作修改 | 创建或更新资源；不自动执行任务，也不自动做连接测试。 |
| 删除 | ADMIN | 已确认，且资源未被引用 | 删除该资源；被引用时拒绝删除。 |
| 批量删除 | ADMIN | 已选择资源并确认；列表未在加载或报错 | 分别尝试删除所选资源，报告成功和失败；不把部分成功显示成全部成功。 |
| 连接测试 | ADMIN | 资源已保存并启用 | 从当前 API 节点访问目标；各类型具体检查见子页。成功不等于 Worker 可达或业务读写权限完整。 |
| 保持不变 | ADMIN | 编辑已有秘密字段 | 保存时保留原值，不要求重新输入秘密。 |
| 替换 | ADMIN | 字段允许修改且新值满足校验 | 保存时替换该字段；数据库密码入口显示为“修改密码”。 |
| 清除 | ADMIN | 该字段显示清除入口，清除后仍满足认证要求 | 保存时显式移除；空白显示或空的替换输入不等于清除。 |
| 显示本次输入的密码 | ADMIN | 正在输入可切换显示的秘密字段 | 仅显示本次输入，不取回已保存秘密。 |

必填秘密（例如 RabbitMQ 密码、S3 访问凭据、OAuth 客户端密钥）不可直接清除。SSH 与 SFTP 至少保留密码或私钥文件路径之一；私钥口令必须与私钥路径配套。请求头通过删除整行移除，不能把空白显示当作清除。

## 操作与结果核对

先创建独立资源，再在任务选择。资源被多个任务共享时，改地址或禁用会影响所有使用者；变更前检查引用。详见数据库、SSH、服务、文件、消息和监控分册。导出包不带凭据，目标环境需重新填写。
