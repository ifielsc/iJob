# 工作区、偏好与节点

[English](../../en/user-guide/workspace.md) · [手册首页](../README.md)

## 入口与操作路径

工作区/概览。页面动作随当前账号权限提供；先确认操作对象及环境。

## 配置和动作说明

| 字段/动作 | 用途与填写规则 |
| --- | --- |
| `登录与身份` | 使用安装时创建的账号；强制改密页完成后再进入业务。无权限动作不会因换 URL 获得权限。 |
| `语言 / 主题 / 显示时区` | 顶部设置中切换中文/英文、浅色/深色及显示时区；不修改调度业务时区。 |
| `节点、角色与新鲜度` | 对照节点名、角色和心跳判断可用性；未知/过期不是零值。 |
| `业务入口` | 从任务开始单步骤；作业组合依赖；运行中心查看实际执行。 |

## 操作与结果核对

首次登录先选择语言，再查看概览与节点。只有 API 页面可用而没有 Worker 时，触发可被受理但不一定执行。需要调整节点范围时见[路由配置](../configuration/routing.md)。
