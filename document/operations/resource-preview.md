# SQL 预览与文件路径浏览

SQL、PUSH、DATA_CHECK 与 ETL 数据库 SQL 编辑器在放大窗口提供查询结果区。执行选区只发送一段选中的 SQL；“查询全文”是显式操作，服务端仍只接受单条 SELECT / WITH 只读查询。预览不创建任务实例、不修改检查点，也不向消息目标发布数据。ETL 文件 SQL 不在本阶段预览范围内。

SQL/PUSH 沿用 `${name}`、默认值和必填变量语法，ETL 数据库读取还支持已有命名参数绑定。预览弹窗仅收集本次语句使用的标量参数，读取已绑定模板的类型、范围及敏感标记；运行时变量必须填写样例值。多参数弹窗固定标题与操作区，仅参数列表内部滚动。参数不保存到任务或浏览器持久存储。SQL 文本、参数和结果不写入协调状态。

默认 200 行、最多 1000 行；最多 256 列，结果最多 2 MiB，单元格最多 16 KiB。二进制内容显示占位符。空值与空字符串区分显示，数值由后端以字符串返回，保留大整数和小数。单次查询限时 30 秒，每节点最多 4 个并发预览。关闭编辑器或点击停止会发送取消请求；协调存储传递同一登录身份的取消标记，执行节点调用 JDBC cancel/abort。请求退出后回滚并释放连接，记录仅按短 TTL 保留。客户端修改 SQL、资源或行数上限后会标记原结果过期。

服务端结合语句检查与数据库只读事务。当前可配置的数据库资源中，MySQL、PostgreSQL、Oracle 支持预览；不能建立只读事务时失败关闭，SQL Server 暂不提供预览。SQLite 用于服务层隔离测试，不扩展资源配置页面的数据库类型列表。数据库资源仍应使用最小权限只读账号，数据库扩展函数的外部副作用由数据库权限约束。错误返回状态、SQLSTATE、可用的字符位置及追踪编号。查询阶段的 JDBC 异常还返回数据库错误码及脱敏后的数据库报错原文：保留原因和表/字段等对象标识，遮蔽所有提交参数、SQL 字面量、回显数据/语句片段、凭据、连接地址及路径；连接建立/事务初始化失败保持概括信息。错误文本最多4096个字符，超过64KiB的原始诊断不展示，前端按纯文本显示且不持久化。前端按明确的 SQLSTATE 显示表/视图不存在、字段不存在、权限不足、类型转换失败等原因；不能唯一判断的状态保留概括提示，不把通用 42000 误判为单纯语法错误。

文件浏览支持现有 LOCAL、FTP、SFTP、S3_COMPATIBLE 文件资源及资源编辑草稿。会话和目录快照在协调存储加密，TTL 120 秒；每目录最多 5000 项、快照最多 512 KiB、每页最多 100 项。搜索仅筛选当前目录快照，刷新重新读取目录，超过限额提示缩小目录。只读取元数据，不读取文件内容、不上传、不删除。SFTP 主机校验沿用文件资源配置。修改时间由服务端输出带Z的UTC时间点，页面按当前显示时区（默认业务时区，也可切换UTC）格式化为`yyyy-MM-dd HH:mm:ss`，列头标明时区。

已有资源只能浏览其根目录内部；路径不能包含父目录、未解析变量或跨盘符。LOCAL 会话绑定发起节点，跨节点请求会要求重新打开。新增 LOCAL 草稿只能从管理员配置的 `app.resource-browser.local-roots` 列表选择起点；默认空列表，保留手工填写路径。部署时在外部配置文件设置绝对路径列表，集群节点应分别配置各自受控目录，不能把整个磁盘或用户目录作为默认起点。配置不进入源码，也不改变已有任务执行路径。

FILE_TRANSFER 源选择文件时回填父目录、转义后的精确 glob，并关闭递归；目标仍选择目录。ETL 普通文件读取和文件输出选择文件路径，增量扫描选择目录；新增输出文件名继续手工填写。PROBE FILE 选择扫描目录。资源配置页面选择的目录回填资源根路径，保存前不会改变资源。

所有浏览和预览接口均要求 `CONFIGURATION_WRITE`，不能通过直接 HTTP 请求绕过界面权限。接口为 `POST /api/sql-preview`、`POST /api/sql-preview/{requestId}/cancel`、`GET /api/file-browser/roots`、`POST /api/file-browser/sessions`、`GET/DELETE /api/file-browser/sessions/{id}`。审计只记录操作、资源标识和结果状态等元数据。
