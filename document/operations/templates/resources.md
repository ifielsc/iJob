# 环境资源登记模板

复制到 `runtime/<env-id>/resources.md`。先填写用途和归属，再创建服务；实际秘密只保存到受限的 `secrets/` 文件。下列资源条目按需重复，未使用的资源标记“未创建”。

| 环境字段 | 填写约定 |
| --- | --- |
| 环境 ID、用途、负责人 | 新的唯一 ID；说明关联测试及维护人 |
| 状态与生命周期 | 默认 planned；注明创建、验收、停止及保留安排 |
| 源码与版本 | Git 提交、源码归档哈希、产品 1.0.0、Local JAR 协议 1、正式数据库 V1 |
| 主机身份 | OS/架构、VM UUID 或实例 ID、创建来源、CPU/内存/磁盘实测 |
| 隔离边界 | 独立实例、账号、数据和网络；默认不连接旧环境，不发送真实通知 |
| 环境入口 | README.md、environment.yaml、config/、secrets/、data/、runs/ |

## 单个资源

| 资源字段 | 必填内容或默认约定 |
| --- | --- |
| 资源 ID、类型与用途 | 如 database-01、sftp-01；说明测试范围 |
| 状态、创建方式、归属证据 | 默认未创建；记录实例身份、Compose project/标签、volume 或远端资源 ID |
| 精确版本与来源 | 版本、版别、官方来源及镜像 digest/校验和；条款确认范围 |
| 地址、端口和网络 | 非秘密 endpoint；默认客体回环或专用容器网络，外部访问显式登记 |
| 数据库属性 | database/schema、字符集、排序规则、隔离级别和必要权限；不适用时说明 |
| 其它资源属性 | SFTP 远端目录与主机指纹及核验来源；队列/vhost、bucket、TLS CA 等 |
| 账号与权限 | 专用账号名、权限范围；不记录口令、token 或私钥 |
| 非秘密配置 | config/<resource-id>/；固定镜像清单 config/images.lock.env |
| 秘密引用 | secrets/<resource-id>/；含秘密的完整应用配置也保存在此目录 |
| 数据、备份和恢复目标 | 独立路径/volume；恢复目标也需登记，不覆盖旧环境 |
| 启停及恢复入口 | 经过验证的脚本/命令、执行位置、前置身份检查和正常停止方式 |
| 写入和故障范围 | 仅本轮拥有的目标；注明是否允许专项 DROP、重建、停机或故障注入 |
| 验证与异常 | runs/<run-id>/reports；保留失败及重试记录，区分通过、预期跳过与未覆盖 |
| 保留和清理 | 默认停止并保留；清理前核对归属，禁止全局 prune 或隐式删除旧环境 |

如本轮无需外部数据库、SFTP 或云资源，在此写明“未创建，无需填写外部凭据”。后续新增资源应先增加登记条目，再建立其配置目录。
